Cara memasang

  1. Tekan tombol biru Unduh Jadwalin, tunggu sampai selesai.
  2. Buka file jadwalin-….apk dari notifikasi atau folder Download.
  3. Bila muncul "Demi keamanan, HP Anda tidak diizinkan menginstal aplikasi tidak dikenal", tekan Setelan → aktifkan Izinkan dari sumber ini → kembali.
  4. Tekan Instal. Bila Play Protect bertanya, pilih Tetap instal.

Pembaruan berikutnya muncul otomatis di dalam aplikasi.
